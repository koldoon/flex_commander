# Обновлённый API

Набросок целевого API. Из `fc_api.dart` не экспортируется и ничем не
используется: это проект, а не код. Решения, стоящие за каждым пунктом,
разобраны в журнале решений (`docs/spec/`).

## Общий вид

```
           +---------------+                   +---------------+
  +--------|  Panel Title  |--------+ +--------|  Panel Title  |--------+
  |        +---------------+        | |        +---------------+        |
  | ..                              | | ..                              |
  | Dir1                            | | Dir1                            |
  | Dir2                            | | Dir2                            |
  | file.txt                        | | file.txt                        |
  |                                 | |                                 |
  | 2 files selected, 4.1 MB        | | notes.txt  12 KB  12-08-2026    |   строка панели
  +---------------------------------+ +---------------------------------+
  +---------------------------------+ +---------------------------------+
  | Copy 3 items  [####----]  [ ! ] | |                                 |   leftStatus
  | Packing       [##------]        | |                                 |   rightStatus
  +---------------------------------+ +---------------------------------+
  >> Command line                                                           bottom
  [ F1 ] [ F2 ] [ F3 ] [ F4 ] [ F5 ] [ F6 ] [ F7 ] [ F8 ] [ F9 ] [ F10 ]    обвязка шелла
```

Области: `left`, `right`, `leftStatus`, `rightStatus`, `bottom`, `fullscreen`.
Перечень закрытый — модуль приносит содержимое области, но не само место.
Ряд функциональных кнопок и рама окна областями **не** являются.

`fullscreen` — стопка: просмотрщик, открытый из результатов поиска, по закрытии
возвращает результаты, а не каталог.

## Что где живёт

- **Строка внутри панели** говорит про содержимое: объект под курсором, сводка
  по пометке, `(Scanning…)` фоновых счётчиков. Это часть панели.
- **Статусная область** говорит про работу: столбец компактных полосок
  прогресса тех работ, чей владелец — соседняя панель. У работы, дошедшей до
  `userActionRequired`, рядом появляется кнопка, открывающая её окно.

## Стопка у каждой области

Область держит не одно состояние, а стопку, и над ней две разные операции.

| | Замена (`setViewportContent`) | Наложение (`push` / `pop`) |
|---|---|---|
| что делает | меняет дно | кладёт поверх |
| прежнее | закрывается, не возвращается | живо: каталог, курсор, аренда |
| для чего | вид панели: таблица, дерево, миниатюры (Г5) | быстрый просмотр (Г4), результаты поиска (Д), просмотрщик и редактор |
| переживает перезапуск | да, как настройка панели | нет |

Наложение **скрывает** то, что под ним: `panelAt` смотрит на верх стопки, и
пока поверх правой области показан просмотрщик, копировать туда нечего.

«Панель есть» — ещё не «в неё можно писать». Результаты поиска — обычная
панель, и копировать из них можно; приёмником они быть не могут, потому что
их провайдер не реализует записи.

`fullscreen` отличается только тем, что его стопка может быть пустой: сняли
последний слой — видно панели. Он же запоминает, какая область была активна до
push, и возвращает ей ввод при pop.

Панель — обычное `ViewportState`, и потому заменяема: другая реализация, другой
набор колонок, другой вид. Результаты поиска и дерево каталогов — такие же
реализации `Panel`, и всё, что работает с панелью, работает и с ними.

## Роли и сроки жизни

| Кто | Живёт | Держит |
|---|---|---|
| `AppCommand` | всё время приложения | ничего; условия читает живьём |
| состояние окна | пока открыто окно | форму, ошибку, ссылку на работу |
| `Operation` | до завершения работы | только статус и снимок `P` |
| `OperationRun` в реестре | пока работу не забыли | `runId`, владельца, команду |

Команда — прототип: один долгоживущий объект на команду. Нижний ряд кнопок и
список команд спрашивают у него `label` и `isExecutable()` сколько угодно раз,
ничего не создавая.

## Правила

- **DI формирует контекст приложения.** Все объекты приложения — сервисы,
  команды, операции — проходят через контейнер. `install` получает узкий
  типизированный фасад, который внутри делает те же биндинги: список `install`
  читается как перечень возможностей модуля.

- **Виды регистрируются по типу состояния**, не по строковому имени: связь
  «состояние ↔ вид» проверяет компилятор. Строковых ключей в системе областей
  нет ни одного.

- **Живое — до `execute`, снимок — после.** Команда читает состояние приложения
  живьём: она короткая и работает «сейчас». Собранное она отдаёт операции
  параметрами, и операция приложения не видит вообще — ни областей, ни панелей,
  ни собственного идентификатора. Иначе фоновое копирование сломается, как
  только панель выйдет из архива.

- **Заявка — это сигнал, а не данные.** Работа говорит «нужен человек», а чем
  спрашивать — лежит в подтипе заявки, который заводит спрашивающий и для
  которого он же регистрирует вид. Поэтому поднять окно может кто угодно, не
  зная, чья это работа: вид находится по типу. Без этого вход в зашифрованный
  архив невозможен — пароль спрашивает архиватор, а чтения каталога ждёт
  панель, и про архивы она ничего не знает. Простой вопрос из кнопок заводить
  не надо: для него есть готовая `ChoiceRequest`, и вид ей рисует ядро.

  `Esc` в окне идущей работы — это «прервать?», а не «спрятать»: работа
  необратима, а `Esc` жмут не глядя. Спрятать — кнопка «в фон», и она не просто
  закрывает окно, а отправляет работу в фон явно: только тогда полоска
  появляется в статусной области. Работа, идущая молча и невидимо, — худшее из
  состояний. Заявка при закрытом окне сама окном не выпрыгивает, но в момент,
  когда работа упёрлась впервые, показывается тост.

  **Операция всегда ждёт ответа** — «по умолчанию, раз никто не слушает» не
  бывает. Отсюда: спрашивать вправе только та работа, которую ждут. Запущенная
  и брошенная — определение типа, подсчёт размеров — спросить не может, она
  повиснет молча; если ей нужно решение, она обязана закончиться ошибкой.

  `Credentials` при этом — не окно, а **память ответов по realm**; живёт в
  контейнере, как остальные службы.

- **Завести работу и отправить её в фон — разные действия.** Заводят, чтобы
  работу можно было найти: собрать ей окно заново, поднять заявку, дождаться.
  В фон отправляют отдельно, и только тогда называют область — где показывать,
  имеет смысл лишь когда показывают. Работу, которую и находить незачем, не
  заводят вовсе: у неё просто зовут `execute`.

- **Активная область — состояние приложения**, а не системный фокус. Над деревом
  фокуса стоит ранний обработчик: он видит нажатие раньше сфокусированного
  виджета, гасит `Esc` (AppKit отвечает на `Cmd+.` бесконечной чередой `Escape`)
  и ищет привязку по содержимому активной области; не нашёл — отдаёт событие
  вниз, а оттуда в ОС, иначе перестанет работать `Cmd+Q`.

- **Панель-источник отдельно от активной области.** Ввод уходит и туда, где
  панели нет — в командную строку, в полноэкранный просмотрщик, — а источник
  файловой операции при этом никуда не девается.

- **Привязка клавиш называет тип содержимого**, а не позицию: в `fullscreen`
  бывает и просмотрщик, и редактор, и терминал, а одна клавиша значит в них
  разное.

- **Сменой активной области занимается команда**, меняющая её между `left` и
  `right` при возможности.

- **За рендер и расстановку областей отвечает `AppShell`** — и он живёт в
  ядре, а не здесь: это не контракт, против которого пишут модули. Его дело —
  разложить шесть областей, нарисовать разделитель по `leftRightSplitRatio`,
  ряд функциональных кнопок и слои окон, тостов и ошибок. Всё, что ему для
  этого нужно, он читает из `ApplicationView`.

- **Окно — не область.** `showDialog` не меняет ни активную область, ни
  панель-источник, поэтому команда из списка команд видит ту же панель, что и
  клавиша. Список команд перед запуском закрывает себя сам: иначе окно команды
  встанет поверх него.

- **Переживают перезапуск только панели, и только адресом.** Наложения не
  сохраняются вовсе; вид панели сохраняется как её настройка. Сохранённый
  `ssh://` считается недоступным — поход на сервер остаётся отдельным решением
  человека, а не ценой запуска.
