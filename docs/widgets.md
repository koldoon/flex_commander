# Виджеты, тема и метрики

Вёрстка следует макету [`design/design.svg`](design/design.svg); числа ниже сняты
непосредственно из него (макет нарисован в масштабе 1×, размеры — логические пиксели).
Поведение виджетов повторяет референсные компоненты `ru.koldoon.fc.c.*`.

## 1. Дерево виджетов

```
FlexCommanderApp                      MaterialApp, тема, AppScope
└── ApplicationView                   Scaffold без AppBar
    ├── Expanded
    │   └── SplitView                 две панели + перетаскиваемый разделитель
    │       ├── PanelScope(left)
    │       │   └── PanelView
    │       │       ├── PanelPathHeader        «плашка» с путём, поверх рамки
    │       │       ├── Expanded
    │       │       │   └── FileTable
    │       │       │       ├── FileTableHeader
    │       │       │       │   └── FileTableHeaderCell × N   (+ полосы захвата границ)
    │       │       │       ├── ColumnDividers               вертикальные линейки на всю высоту
    │       │       │       └── ListView.builder
    │       │       │           └── FileTableRow × N
    │       │       └── PanelStatusBar
    │       ├── SplitHandle
    │       └── PanelScope(right) → PanelView
    └── FunctionBar
        └── FunctionButton × 10
```

## 2. Виджеты

### `ApplicationView`

Корневой макет: `Column` из растянутого `SplitView` и `FunctionBar` внизу.
Оборачивает всё в `Focus` верхнего уровня, который перехватывает клавиатуру
и передаёт комбинации в `CommandRegistry` (см. [`keyboard.md`](keyboard.md)).

Фон окна — светло-серый градиент, панели рисуются поверх с отступом 3 px.

### `SplitView`

Две панели одинакового поведения и перетаскиваемый разделитель между ними.

- Ширина левой панели = `constraints.maxWidth * app.splitRatio`, минимум 200 px на панель.
- Перетаскивание разделителя меняет `splitRatio` в `AppController`; значение
  сохраняется в настройках.
- Двойной клик по разделителю возвращает `0.5`.
- Курсор мыши над разделителем — `SystemMouseCursors.resizeColumn`.

### `PanelView`

Панель целиком. Не знает, левая она или правая: всё берёт из `PanelScope`.

- Фон белый, рамка 1 px `#CCCCCC`, скругление 3 px.
- `GestureDetector` на всей площади: нажатие мышью делает панель активной
  (`AppController.activate`) — поведение референса (`onPanelMouseDown`).
- Пока `panel.busy`, поверх содержимого — полупрозрачная заглушка с индикатором,
  клики не проходят.
- При `panel.status == error` вместо списка показывается сообщение об ошибке
  и подсказка `Backspace — на уровень вверх`.

### `PanelPathHeader`

«Плашка» с текущим путём: скруглённый прямоугольник, наложенный на верхнюю рамку панели.

- Размер: высота 21, скругление 3, горизонтально по центру панели,
  максимальная ширина — ширина панели минус 40.
- Активная панель: фон `#0169D9`, рамка `#0063CD`, текст белый.
- Неактивная: фон `#B0B1AF`, рамка `#A0A0A0`, текст белый.
- Текст — `directory.pathString`, одна строка, обрезка **слева** с многоточием
  (важнее видеть конец пути), тултип с полным путём.
- Клик — выделение пути для копирования (после MVP: редактирование пути вводом).

### `FileTable`

Таблица: строка заголовков, вертикальные линейки-разделители колонок и прокручиваемый список.

- Ширины колонок вычисляются один раз на `LayoutBuilder` и передаются вниз готовым
  списком `List<double>`, чтобы каждая строка не пересчитывала раскладку.
- Вертикальные линейки (`ColumnDividers`) рисуются **на всю высоту таблицы**, от строки
  заголовков до низа списка — как в макете (в референсе это отдельные компоненты `PanelLine`).
  Цвет — `#000000` с прозрачностью 12 %.
- Список — `ListView.builder` с `itemExtent: 20` (фиксированная высота строки даёт
  дешёвый скролл и точный `ensureVisible` для тысяч записей).
- Прокрутка к курсору — `ScrollController.animateTo` без анимации (мгновенно),
  с полем в одну строку сверху и снизу, чтобы курсор не прилипал к краю.
- Вертикальный скроллбар — всегда видим (как в референсе: `verticalScrollPolicy="on"`),
  иначе ширина колонок «прыгает» при появлении полосы.
- Одиночный клик ставит курсор и активирует панель, двойной по той же строке —
  входит в объект. Двойной клик распознаётся вручную, по времени и индексу строки:
  штатный `onDoubleTap` заставляет Flutter придержать одиночный клик до истечения
  таймаута, а курсор должен переставляться сразу.

### `FileTableHeader` и `FileTableHeaderCell`

- Высота строки заголовков 26, текст 12 px, цвет `#333333`, фон панели.
В одной строке уживаются три жеста:

- **Клик** по ячейке — `panel.sortBy(column)`; та же колонка меняет направление.
  Индикатор сортировки — треугольник (`▾`/`▴`) **перед** текстом заголовка, как в макете
  и в референсном `ColumnHeader`; показывается только у активной колонки.
- **Перетаскивание ячейки** — перестановка колонок. Пока идёт перетаскивание, ячейка
  приглушена, а место будущей вставки помечается вертикальной полосой. Обязательные
  колонки (иконка и имя) не двигаются и не пропускают другие вперёд себя.
- **Перетаскивание границы** — ширина колонки. Полосы захвата шириной 7 px лежат на
  левых краях колонок фиксированной ширины; граница — это левый край, поэтому движение
  влево колонку расширяет, а «резиновое» имя поглощает разницу. Ширина не опускается
  ниже `minWidth`.

Клик и перетаскивание уживаются на одной ячейке: без движения срабатывает сортировка,
с движением — перестановка.

Правый клик по строке заголовков открывает меню видимости: список всех колонок
с отметками (обязательные недоступны) и пункт «Reset columns», возвращающий раскладку
по умолчанию.

Любое изменение уходит в `panel.setColumnLayout` и дальше в настройки; панель при этом
становится активной.

### `FileTableRow`

Одна строка; собственного состояния не имеет — всё приходит параметрами.
Перестроением управляет список: он подписан сразу на панель и на пометку
(`Listenable.merge`). При фиксированной высоте строки `ListView` строит только
видимые ~25 строк, поэтому отдельная подписка на каждую строку не нужна.

Содержимое ячеек (правила из референсного `FileItemRenderer`):

| Колонка | Что показывает |
|---|---|
| `icon` | папка / ссылка / исполняемый файл; у обычного файла иконки нет |
| `name` | имя **без** расширения, если колонка `ext` видима; иначе имя целиком |
| `ext` | расширение; для каталогов и `..` — пусто |
| `size` | `formatSize(size)`; для каталогов и `..` — пусто |
| `modified` / `created` / `accessed` | `formatDate(...)`; для `..` — пусто |
| `attributes` | `attributes.modeString` |

Состояния строки (порядок наложения — снизу вверх):

1. Обычная: фон панели, текст `#444444`, имя каталога — `#333333`.
2. Помечена (выделена пользователем): два признака одновременно —
   слегка подсвеченный фон `#EDEDED` и вертикальная полоса `#4BB9F4`
   шириной 3 px у левого края строки. Полоса — главный признак: она читается
   и тогда, когда строка вдобавок под курсором.
3. Курсор: фон `#0169D9`, весь текст белый; полоса пометки остаётся видимой поверх.

Курсор рисуется **только в активной панели** (поведение референса). Неактивная панель
показывает список без курсора; её позиция запоминается в `PanelController` и
восстанавливается при активации. Помеченные строки видны в обеих панелях одинаково —
пометка не зависит от того, какая панель активна.

Строка не имеет hover-подсветки: она мешает читать список и не предусмотрена макетом.

### `FileTypeIcon`

- Каталог — папка, `#4BB9F4`.
- Ссылка — стрелка/звено; если цель разрешена и это каталог, рисуется папка со стрелкой.
- Исполняемый файл — звёздочка (референс: `fa_asterisk`).
- Обычный файл — пусто (иконка не рисуется, место резервируется).
- Битый узел (`broken`) — восклицательный знак, цвет `#DE1D2E`.

Размер 16, в колонке шириной 24. В MVP используются `Icons.*` из Material;
позже можно заменить на собственный шрифт иконок (в референсе — FontAwesome).

### `PanelStatusBar`

Высота 24, отделена сверху горизонтальной линией, текст 12 px слева.

Содержимое по приоритету (правила `getSelectionInfoText` из референса):

1. `panel.statusText`, если его выставила команда (`Loading…`, текст ошибки);
2. `Selected N items, 12.4M`, если есть помеченные объекты;
3. `name -> target` для ссылки под курсором;
4. имя объекта под курсором;
5. `-`, если панель пуста.

### `FunctionBar` и `FunctionButton`

Ряд из 10 кнопок, растянутых на всю ширину окна равными долями, высота полосы 27.

- Кнопка: подпись «F1» слева серым (`#737373`), затем скруглённая кнопка (высота 21,
  скругление 3, рамка `#000000` 27 %, фон — светлый градиент) с названием команды.
- Содержимое берётся из `CommandRegistry.commandForSlot(FunctionKeySlot.f1…f10)`:
  подпись — из команды, отсутствие команды даёт `-`.
- Кнопка неактивна (приглушена, клики игнорируются), если `isExecutable() == false`
  для текущего состояния активной панели.
- Клик по кнопке выполняет ровно ту же команду, что и нажатие клавиши.
- При зажатом `Shift` подписи меняются на команды `Shift-F*` (после MVP).

## 3. Тема

Тема задаётся `ThemeExtension`, чтобы палитра и метрики не растекались по виджетам:

```dart
class FcTheme extends ThemeExtension<FcTheme> {
  final FcColors colors;
  final FcMetrics metrics;
  final TextStyle rowStyle;
  final TextStyle headerStyle;
}
```

Доступ: `Theme.of(context).extension<FcTheme>()!`. Хардкод цветов и размеров в виджетах
недопустим — иначе вторая тема (тёмная, как в референсном приложении) потребует правок
по всему дереву.

### Палитра (светлая тема, из макета)

| Роль | Значение |
|---|---|
| Фон окна | градиент `#FAFAFA` → `#D9D9D9` |
| Фон панели | `#FFFFFF` |
| Рамка панели, разделители | `#CCCCCC` |
| Линейки колонок | `#000000`, прозрачность 12 % |
| Текст строки | `#444444` |
| Текст имени каталога | `#333333` |
| Текст размера | `#555555` |
| Вторичный текст (подписи F-клавиш) | `#737373` |
| Заголовки колонок | `#333333` |
| Курсор (только в активной панели) | фон `#0169D9`, рамка `#0063CD`, текст `#FFFFFF` |
| Фон помеченной строки | `#EDEDED` |
| Полоса пометки, иконка папки | `#4BB9F4` |
| Ошибка | `#DE1D2E` |
| Фон кнопки F-панели | градиент `#FDFDFD` → `#F1F1F1`, рамка `#000000` 27 % |

Тёмная тема (палитра референса: фон `#011130`, панель — белый с прозрачностью 5 %,
курсор `#15387E`, текст `#9AA7C1`) описывается тем же `FcColors` и включается
через `themeMode` из настроек. В MVP реализуется только светлая, но константы
не должны этому мешать.

| Параметр | Значение |

| Отступ окна до панелей | 3 |
| Зазор между панелями | 3 |

Шрифт: системный UI-шрифт платформы (макет нарисован в Avenir/Ubuntu — это не важно).

(`fontFeatures: [FontFeature.tabularFigures()]`), иначе числа в столбце «прыгают».

## 4. Производительность

- `itemExtent` у списка обязателен: без него `ListView` считает высоты и тормозит
  на больших каталогах.
- Все константные виджеты — `const`; строка файла не должна создавать `TextStyle`
  на каждый кадр (стили берутся из темы один раз в `build` таблицы и передаются вниз).
- `RepaintBoundary` на строке не нужен — при `itemExtent` перерисовка и так локальная;
  а вот на `FunctionBar` он полезен, чтобы прокрутка списка её не трогала.
- Цель: 60 fps на каталоге в 100 000 элементов; чтение такого каталога уходит в изолят,
  на время чтения панель показывает индикатор и остаётся отзывчивой.

## 5. Что проверяется golden-тестами

- Пустой каталог, каталог с `..`, длинные имена с обрезкой.
- Активная и неактивная панель: цвет плашки пути; в неактивной курсора нет.
- Помеченные строки (фон + полоса слева) и строка, помеченная и под курсором одновременно.
- Все колонки включены (проверка горизонтальной прокрутки).
- Панель в состоянии ошибки доступа.
