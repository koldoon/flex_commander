# Встроенные наборы клавиш: mc, far, Finder

**Состояние:** сделано. Отметки по ходу — в §9.

Этап В6. Вторые клавиши у одной команды — `F8` и `Cmd-Bsp` у удаления, `F7` и
`Shift-Cmd-N` у создания каталога, `Cmd-I` и `Alt-Enter` у сведений — заведены не
потому, что делу нужно два вызова, а потому, что люди приходят из разных
файловых менеджеров. Это разные **привычки**, и закрывать их надо набором, а не
россыпью синонимов.

Механизм уже есть: набор это тот же пресет (`settings-presets.md`), только
объявленный приложением, а не сложенный человеком.

## 1. Что получается

В списке наборов появляются три, которых человек не складывал: **mc**, **far**,
**Finder**. Выбрал — клавиши стали как там. Всё прочее не тронуто: набор кладётся
накладкой и говорит только о клавишах (`settings-presets.md`, §4).

## 2. Привязка — это дело

Набор перечисляет пары «имя привязки → клавиша» (`KeyOverride {binding, key}`).
Имя — то самое, которым привязку назвал модуль (`key-bindings.md`, §3): у дела,
которое у команды одно, это идентификатор команды; там, где дел несколько, —
своё имя (`panel.view.brief`).

Отсюда доктринальный тест: **у каждой записи всех наборов есть привязка с таким
именем**. Без него набор однажды тихо перестанет работать — достаточно
переименовать привязку в модуле.

## 3. Прополка: одна клавиша на дело

Вторые клавиши, заведённые ради привычек, из модулей убираются. Умолчанием
приложения остаётся **классическая** — та, что обещает ряд кнопок внизу:

| дело | остаётся | уходит |
|---|---|---|
| удалить | `F8` | `Cmd-Bsp` |
| удалить мимо корзины | `Shift-F8` | `Shift-Cmd-Bsp` |
| создать каталог | `F7` | `Shift-Cmd-N` |
| сведения | `Alt-Enter` | `Cmd-I` |
| атрибуты | `Ctrl-A` | `Cmd-Shift-I` |
| скрытые файлы | `Cmd-Shift-H` | `Cmd-H` |
| наверх | `Bsp` | `Cmd-Up` |
| назад и вперёд по истории | `Alt-Left`, `Alt-Right` | `Cmd-[`, `Cmd-]` |
| пометить | `Space` | `Ins` |
| искать в тексте | `F7` | `Cmd-F` |
| искать дальше | `Shift-F7` | `Cmd-G` |
| сохранить | `F2` | `Cmd-S` |

**Пометка остаётся на `Space`, а не на `Ins`** — вопреки правилу: клавиши
`Insert` на клавиатурах Apple нет вовсе, и «классическая» оставила бы дело
недостижимым.

**`Cmd-H` уходит ещё и потому, что до приложения не доходит**: на macOS это
«скрыть приложение».

Не считается дублированием и остаётся:

* `Shift-=` и `+` у пометки по маске, `+` и `=` у масштаба картинки — это
  **разные физические клавиши** (основная и цифровой блок), а не две привычки;
* `F9` в панели и `Cmd-,` везде у настроек — это **разные контексты**.

## 4. Наборы

Собраны **по духу**, а не буквально: привычка оригинала берётся там, где она
работает; занятое системой macOS не берётся вовсе — такая клавиша не дойдёт до
приложения, и набор молча недосчитался бы дела.

О чём набор молчит — остаётся умолчание приложения.

### mc

| дело | клавиша |
|---|---|
| обновить | `Ctrl-R` |
| скрытые файлы | `Alt-.` |
| наверх | `Ctrl-PgUp` |
| пометить | `Ins` |
| вставить имя в командную строку | `Ctrl-Enter` |

`F1`…`F8`, `Tab`, `Ctrl-O`, `Alt-O`, `+`/`-` и `Ctrl-S` совпадают с оригиналом и
так — в наборе их нет.

### far

| дело | клавиша |
|---|---|
| копировать в буфер | `Ctrl-Ins` |
| вставить из буфера | `Shift-Ins` |
| вырезать в буфер | `Shift-Del` |
| обновить | `Ctrl-R` |
| скрытые файлы | `Ctrl-H` |
| в корень | `Ctrl-\` |
| история каталогов | `Alt-F12` |
| адрес левой и правой панели | `Alt-F1`, `Alt-F2` |
| выбор вида панели | `Cmd-F1`, `Cmd-F2` |

`Ctrl-A`, `Alt-F7` и ряд `F1`…`F8` совпадают и так. Адрес и выбор вида **меняются
местами**: в far на `Alt-F1`/`Alt-F2` выбирают диск, а это ближе всего к нашему
адресу панели.

### Finder

| дело | клавиша |
|---|---|
| быстрый просмотр | `Space` |
| пометить | `Ins` |
| скрытые файлы | `Shift-Cmd-.` |
| поиск файлов | `Cmd-F` |
| новая сессия | `Cmd-T` |
| командная строка | `Cmd-Shift-T` |
| вид: значки, таблица, колонки | `Cmd-1`, `Cmd-2`, `Cmd-3` |
| удалить | `Cmd-Bsp` |
| сведения | `Cmd-I` |
| создать каталог | `Shift-Cmd-N` |
| наверх | `Cmd-Up` |
| назад и вперёд | `Cmd-[`, `Cmd-]` |
| сохранить в редакторе | `Cmd-S` |
| искать в тексте, искать дальше | `Cmd-F`, `Cmd-G` |

`Space` занят пометкой, поэтому пометка уезжает на `Ins`: в Finder пробел это
быстрый просмотр, и ради него набор и нужен. `Cmd-W` (закрыть вкладку) не
берётся — на macOS это системное сочетание.

## 5. Как объявляются

Своим модулем (`fc.key_presets`): он ничего не делает, кроме как объявляет три
набора.

```dart
registry.preset(Preset(name: 'mc', keys: [KeyOverride(binding: 'panel.reload', key: 'Ctrl-R'), …]));
```

`FrontendRegistry.preset` — новая запись рядом с `command` и `binding`.
Собранное отдаёт служба `PresetCatalog`, а список наборов складывается так:
**встроенные впереди, свои следом**.

## 6. Встроенный набор — не свой

| | |
|---|---|
| выбрать | можно |
| `Export` | можно — это и есть способ сделать его своим |
| `Update`, `Delete` | нельзя: кнопки приглушены |
| `New` | складывает **нынешнее** под своим именем, как и всегда |

Имя встроенного занято навсегда: «сложить» под таким именем отвергается, а
свободное имя его обходит. Иначе свой «mc» затёр бы встроенный, а тот при
следующем запуске вернулся бы и затёр своё.

## 7. Проверка

* **Имена уникальны** у всех настраиваемых привязок — иначе набору некуда
  целиться.
* **Каждая запись набора находит свою привязку.**
* **Набор применяется**: «mc» — `Ctrl-R` обновляет, `Cmd-R` больше нет;
  «Finder» — `Space` показывает быстрый просмотр, а не помечает.
* **Молчание ничего не меняет**: после «mc» тема и язык прежние, `F5`
  по-прежнему копирует.
* **Встроенный не свой**: «Update» и «Delete» приглушены, имя занято.
* **Прополка**: у каждого дела ровно одна клавиша, кроме названных исключений.
* **Живьём**: выбрать «mc», нажать `Ctrl-R` и `Alt-.`; «Finder» — `Space` на
  файле; вернуться к «Default».

## 8. Чего в этой версии нет

* **Наборов для настроек** — только клавиши: тема и раскладка панелей у
  привычек разные, а угадывать их за человека незачем.
* **Своего набора поверх встроенного**: выбрал «mc» и правь дальше — правки
  лягут поверх обычным переназначением.
* **Наборов для просмотрщика и редактора сверх названного**: там привычки
  ближе к системе, чем к файловому менеджеру.

## 9. Отметки по ходу

* Ветка `key-presets`. Спека написана до кода.
* **Привязка стала делом.** Переназначение опознаёт её именем, а не парой
  «команда и прежняя клавиша»: `was` имел бы смысл, будь у команды несколько
  клавиш, из которых переписывают одну. Отсюда и обратное правило — смена
  умолчания в новом выпуске больше **не рвёт** переназначение.
* **Доктринальный тест на уникальность имён нашёл первые дубли сразу**:
  настройки (`F9` в панели и `Cmd-,` везде) и масштаб картинки (`+` и `=`). Оба
  законны — разные контексты и разные физические клавиши, — и потому получили
  свои имена.
* **Прополка задела тесты, а не только модули**: полтора десятка проверок
  закрепляли ровно те вторые клавиши, которые убраны. Каждая переписана на
  новое правило, а не подогнана.
* **Окно атрибутов в тесте открывается командой**, а не нажатием: вне macOS
  «командная» клавиша сворачивается в `Ctrl`, и `Ctrl-A` атрибутов становится
  неотличим от `Cmd-A` пометки всего. На самой macOS это разные сочетания.
