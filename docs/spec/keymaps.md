# Наборы клавиш вместо пресетов

**Состояние:** сделано, ждёт живой проверки. Отметки по ходу — в §9.

## 1. Зачем

Пресеты (`settings-presets.md`) задумывались как снимок **всего** выбора —
настроек и клавиш. На деле они почти целиком про клавиши: встроенные mc, far и
Finder — это только клавиши, а прочих настроек немного, и набором их никто не
возит. Раздел «Presets» стоял первым в настройках, хотя говорил в основном о
клавиатуре, а сама клавиатура была разделом из одной кнопки.

Решено (2 октября 2026):

* **раздел «Presets» убирается совсем**;
* **раздел «Keyboard» устроен как раздел тем**: список наборов клавиш и ряд
  кнопок `New`, `Edit`, `Delete`, `Export`, `Import`; `Edit` открывает нынешнее
  окно клавиш;
* **раздел «Themes» переименован в «Appearance»** — так это называют в
  macOS и в большинстве приложений.

## 2. Набор клавиш

`Keymap {name, keys: List<KeyOverride>}` — имя и переназначения, тем же
списком, каким они живут в настройках.

* **Default** — набор без переназначений: умолчания приложения.
* **Встроенные** — mc, far, Finder (`key-presets.md`); объявляет их модуль
  (`registry.keymap`), как прежде объявлял пресеты.
* **Свои** — сложенные человеком: `New` кладёт нынешние клавиши под новым
  именем и выбирает его.

Выбранный набор — то, что сейчас действует. Его клавиши — это
`Application.keyOverrides`, как и раньше; окно клавиш правит их же.

## 3. Правка — у каждого набора своя

Как у тем: правка встроенного набора помнится **при нём**, а не теряется при
переключении. Ушли с mc на far — то, что поправили в mc, лежит при mc и
вернётся, когда mc выберут снова.

* Выбранного набора клавиши — `keyOverrides`.
* Невыбранные — их последнее состояние в `keymapEdits` (имя → клавиши); у
  встроенного, которого не трогали, записи нет — берётся объявленное.
* **«Reset all keys»** в окне клавиш возвращает выбранный набор к **его**
  началу: встроенный — к объявленному модулем, Default и свои — к умолчаниям
  приложения.

## 4. Кнопки раздела

| | выбран Default | выбран встроенный | выбран свой |
|---|---|---|---|
| `New` | да | да | да |
| `Edit` | да | да | да |
| `Delete` | приглушена | приглушена | да, с подтверждением |
| `Export` | приглушена | да | да |
| `Import` | да | да | да |

`Export` пишет `{name, keys}` в json; `Import` читает его же — и прежние файлы
пресетов: у них есть `name` и `keys`, а `settings` пропускается. Имя занято —
приписывается номер, как было у пресетов.

## 5. Переезд

Читается один раз, при первом запуске новой версии, из того, что лежит в
настройках:

* каждый свой пресет, в котором есть клавиши, становится своим набором клавиш
  с тем же именем;
* выбранный пресет становится выбранным набором (встроенный — встроенным,
  свой — переехавшим своим);
* пресеты после этого очищаются: читать их больше некому.

Настройки, лежавшие в пресетах, не переезжают никуда — их там было немного, и
возить их набором раздел больше не будет. Нынешние настройки, конечно, остаются
как стоят.

## 6. Где лежит

В настройках приложения, рядом с `keys`: `keymap` (имя выбранного; пусто —
Default), `keymaps` (свои: `{name, keys}`), `keymapEdits` (имя → клавиши
невыбранных). Разбор — из любого словаря, а не только `Map<String, dynamic>`
(память: «списки в разделе модуля»).

## 7. Что меняется в коде

* `fc_api`: `Keymap` (сериализуемый), поля в `AppSettings`; `Preset` остаётся
  только для чтения при переезде.
* `ui_api`: `Application.keymap`, `keymaps`, `keymapEdits` и одна правка
  `setKeymaps(...)`; `KeymapCatalog` вместо `PresetCatalog`;
  `registry.keymap(...)`.
* `lib/state/keymaps.dart` — выбор, `New`, `Delete`, переключение с запоминанием
  правки, возврат к началу, добавление пришедшего; `keymap_files.dart` —
  выгрузка и загрузка.
* `app_shell.dart` (модуль оболочки): раздел «Keyboard» — список и кнопки;
  раздел «Presets» убран; «Themes» → «Appearance».
* `KeysCommand`: «Reset all keys» — к началу выбранного набора.

## 8. Проверка

* выбор набора меняет клавиши; правка в окне клавиш остаётся при наборе после
  переключения туда и обратно;
* `New` — копия нынешних клавиш под новым именем, выбрана;
* `Delete` — только свой; выбранный удалили — выбран Default;
* «Reset all keys» у встроенного — объявленные клавиши, у своего — умолчания;
* выгрузка и загрузка; загрузка старого файла пресета;
* переезд: свои пресеты с клавишами → свои наборы, выбранный сохраняется;
* круг через JSON с новым запуском;
* раздела «Presets» нет, «Appearance» есть.
